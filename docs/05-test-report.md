# תיעוד הבדיקות — PayrollPortal

מסמך זה מתעד **איך** בדקנו ו**מה** יצא, מול האפיון ב-[04-test-spec.md](04-test-spec.md).

סטטוס אוטומציה: סוויטת בדיקות יחידה אוטומטית מלאה מומשה באמצעות Node.js Test Runner / `tsx --test` עם **20/20 בדיקות עוברות (100% Pass)** המכסות את הלוגיקה הטהורה (`lib/domain/`), ולידציות Zod, שידוך תלושים ותובנות שכר (ראו סעיף 5).

## 3. באגים שנמצאו וטופלו במהלך הפיתוח

הפריטים הבאים תועדו כי הם משפיעים על איך בודקים היום:

1. **תפקיד ב-`user_metadata`** — נחסם באפיון האבטחה. הרשמה ישנה עם בחירת Worker/Manager הוסרה. בדיקת A12 היא הרגרסיה.
2. **`DEV_AUTH_ROLE` דרס סשן אמיתי** — תוקן: סשן אמיתי תמיד מנצח. אחרת עובד מחובר היה נזרק ל-shell של משרד.
3. **הפניה ב-`proxy.ts` זרקה עוגיית רענון** — תוקן ב-`withRefreshedCookies` ב-`proxy.ts` (תמיכה מלאה ב-Next.js 16 Proxy Convention).
4. **הקצאת תלוש אוטומטית** — נדחתה במכוון. הבדיקה F3.3 חייבת לוודא ששידוך הוא הצעה.
5. **אישור חופשה רק למנהל קו** — הורחב ב-0006 לכל מנהל בעסק + משרד, כדי שבקשה לא תיתקע. A6 עדיין אוסר אישור עצמי.
6. **Error & Loading Boundaries** — מומשו גבולות שגיאה וטעינה מקומיים (`error.tsx` ו-`loading.tsx`) לכל תיקיית תפקיד (`bookkeeper`, `employee`, `manager`).

## 5. אוטומציה ממומשת (קוד הבדיקות תחת tests/)

סוויטת בדיקות יחידה אוטומטית מלאה מומשה תחת `tests/` ומורצת בפקודה `npm test`:

1. **`tests/working-days.test.ts`**:
   - `isIsoDate` תקינות מחרוזות תאריך ישראלי (דחיית 2026-02-29).
   - `countWorkingDays` דילוג על סופ״ש ישראלי (שישי, שבת).
   - ניכוי חגים מלאים (0 ימים) וערבי חג (0.5 יום).
   - חישוב יתרה יחסית (`entitledDaysForYear`) לעובד שהצטרף באמצע השנה.
   - זיהוי חפיפות טווחים (`rangesOverlap`).

2. **`tests/insights.test.ts`**:
   - חישוב תובנות שכר, דלתא מול חודש קודם, אחוז שינוי.
   - ממוצע מתגלגל של 12 חודשים (מינימום 3 חודשים).
   - שיעור ניכויים וסיווג תנודתיות שכר (`stable` / `some` / `variable`).

3. **`tests/validations.test.ts`**:
   - סכימת התחברות והרשמת משרד ב-Zod (התאמת סיסמאות, אישור תנאים).
   - תקינות בקשות חופשה (דחיית תאריך סוף לפני התחלה, טווח מעל 90 יום).
   - תקינות החלטת חופשה (חובת נימוק בדחייה).
   - תקינות תלושי שכר (חובת ברוטו >= נטו, חודש 1–12).

4. **`tests/payslip-parser.test.ts`**:
   - שידוך עובד לפי ת.ז. ישראלית או מספר עובד (`matchEmployeeById`).
   - ניקוי תווים מיוחדים ומקפים בזמן זיהוי.
